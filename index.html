NFC 태그 사용법

차량용 NFC 스티커에 아래 주소를 등록해두면, 태그만 찍어도 출발/도착이 자동으로 기록돼요.

https://jhkang7989-wq.github.io/DriveLog/?action=toggle
안드로이드
  1. "NFC Tools" 앱 설치 (플레이스토어)
  2. 앱 실행 → "쓰기" 탭
  3. "레코드 추가" → "URL/URI" 선택
  4. 위 주소 붙여넣기
  5. "쓰기" 누르고 폰을 태그에 가까이 대기
아이폰
  1. "단축어" 앱 → "자동화" 탭
  2. "+" → "개인 자동화 생성" → "NFC" 선택
  3. 태그에 폰 대서 스캔/등록
  4. 동작 추가 → "URL 열기" → 위 주소 입력
  5. "실행 전 확인" 옵션은 꺼두기
태그를 찍었는데 안 될 때
  • 폰 설정에서 NFC 기능이 켜져 있는지 확인
  • 화면이 꺼져있거나 잠긴 상태면 인식 안 되는 기종이 많아요 — 화면 켜고 시도
  • 태그 대는 위치는 보통 휴대폰 후면 상단~중앙 (삼성페이 찍는 자리와 동일)
  • 브라우저로 열린다면 → 설정 → 앱 → DriveLog → 열기 → "지원되는 링크"에서 이 도메인을 켜주세요
